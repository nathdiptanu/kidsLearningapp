# SproutLab 0.1.9 expansion portfolio

Step-wise build for ages 3–7. Package `com.sproutlab.kids`. Progress IDs stay stable. Existing 5-free-per-engine entitlement is unchanged. Device speech remains the interim voice (not reviewed recordings). India outlines stay the Survey of India source already in the app; no new invented borders.

## Steps

1. Sequential unlock: level N opens only after level N−1 is finished. Replay of finished levels stays open.
2. Add 50 catalog slots per learning engine (maths, English, patterns, mazes, matching, knowledge). Observation also gains a 50-level connect-the-dots game.
3. Teach-then-try: multiplication, division, grammar, Hindi words, and India facts show a short lesson first.
4. Connect the dots / stars: free-flow stroke, not tap-each-cell. Wrong path is shown gently.
5. India GK: 50+ extra questions on rivers, lakes, dams, metro cities, monuments (who built, why, impact), and state culture / language / tradition. Real map first.
6. Hindi: letter-to-word families, meanings, spoken name via installed offline voice.
7. Tests, then signed Play AAB `0.1.9+11`.

## Honest limits

No new monument photographs or human audio recordings are invented. Extra monument facts use the six licensed photos already bundled. Map geometry is the existing Survey of India educational rendering.
